# ונקובר וייטקאפס

אפליקציה לילדים לקראת משחקי הפלייאוף של ונקובר וייטקאפס.
כל בוקר מתעדכן כרטיס יומי חדש, ולצידו שלוש לשוניות קבועות: ההרכב, המגרש והדרך לגביע.

**באוויר:** https://aybc2025.github.io/whitecaps/

- התקנה בטלפון (אנדרואיד): Chrome → ⋮ → **Install app** (לא "Add to home screen").
- התקנה באייפון: Safari → שיתוף → **Add to Home Screen**.
- להורים: לחיצה ארוכה על הספירה לאחור מציגה את המקורות של הכרטיס של היום.

How it works and how to change it: see `CLAUDE.md`. The daily task's rules: `DAILY_TASK.md`.
